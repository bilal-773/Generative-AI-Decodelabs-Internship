📐 Prompt engineering templates used

Risk extraction prompt
Extract all RISKS from this document. For each risk, cite the exact section/clause number. Do not infer or hallucinate. Format: numbered list.
Date extraction prompt
Extract all DATES and DEADLINES. For each, cite the exact section. If no date is specified for a clause, say "unspecified". Format as table.
Stakeholder extraction prompt
Identify all PARTIES and STAKEHOLDERS. For each, describe their role and cite the first section they appear in. Do not assume roles not stated.
Citation-enforced Q&A prompt
Answer ONLY from the provided document. For every claim you make, add [Section X] or [Clause Y] citation. If the answer is not in the document, say "Not found in document."
